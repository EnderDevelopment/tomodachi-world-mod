# TomodachiWorld

TomodachiWorld is a Minecraft Java Edition mod for Fabric 1.20.1 that brings Tomodachi-inspired features to your game. This mod adds a Steve guide NPC that you can spawn with a custom egg, talk to, and interact with through a city-name entry screen, plus a beta-reference zombie for nostalgic vibes. The mod includes custom entities, spawn eggs, a creative item tab, and a fully functional GUI for naming your city.

## Install

1. Install **Fabric Loader 1.20.1** for your Minecraft launcher.
2. Download and place the **Fabric API 1.20.1** jar into your `mods` folder (required).
3. Build the mod jar by running `./gradlew build` in the project directory, or download a pre-built release.
4. Copy the resulting `tomodachiworld-1.0.0.jar` file into your `mods` folder.
5. Launch Minecraft with the Fabric profile.

## Use

1. Open your inventory and find the **Tomodachi World** creative tab.
2. Take the **Steve Guide Spawn Egg** and right-click on the ground to spawn Steve.
3. Walk up to Steve and **right-click with an empty hand**:
   - He will send his intro dialogue in chat.
   - The **City Name** screen will open so you can type a name for your city.
   - Press `Esc` to confirm and close the screen.
4. Use the **Beta Zombie Spawn Egg** to summon the beta zombie for a classic Minecraft feel.
